# Portfolio Assets & Images Directory

Place your custom images in this directory:
- **Profile Image**: Save your picture as `public/assets/images/profile.jpg` (reference in `portfolioData.ts` as `/assets/images/profile.jpg`).
- **Project Images**: Save project screenshots in `public/assets/images/projects/` (reference as `/assets/images/projects/project1.jpg`).
- **Resume / CV**: Copy your CV to `public/Elia_AbdelMassih_CV.pdf` (reference as `/Elia_AbdelMassih_CV.pdf`).
